# Test APK

`CallShield-Agent-v0.2.0-debug.apk` is a debug-signed evaluation build with package ID `com.storm.callshield`. It can be installed on Android 8+, with call screening primarily targeted at Android 10+.

Download the APK and its SHA-256 checksum from GitHub Releases. Configure the backend and start with the text demo. Microphone analysis requires explicitly enabled backend ASR and user consent.

This package does not overwrite the legacy application. It is not a production-signed or store-ready release. Real-device call-audio behavior still requires testing.
