# Changelog

## 0.2.0 — Initial public English release

- Independent Java Android app with Room-backed local screening and a bounded allow fallback.
- Explicitly consented microphone sessions, bounded WAV uploads, and optional local Whisper ASR.
- Five specialist LangGraph nodes with a rule baseline and optional semantic-model inference.
- Evidence, uncertainty, risk explanations, notifications, and temporary suspicious-number feedback.
- Idempotent uploads, pending-analysis guards, record deletion, tests, and synthetic evaluation.
- English app UI, notifications, API explanations, documentation, filenames, and release material.
- Public source packaging excludes local credentials, runtime data, SDK paths, and build caches.
